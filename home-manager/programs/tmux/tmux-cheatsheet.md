# tmux Cheatsheet

Prefix: `Ctrl+b`

## Panes (splits)

| Action | Key |
|--------|-----|
| Split horizontal (side by side) | `prefix` + `\|` |
| Split vertical (top/bottom) | `prefix` + `-` |
| Navigate panes | `prefix` + `h/j/k/l` |
| Resize pane | `prefix` + arrow keys (repeatable) |
| Close pane | `prefix` + `x` → `y` / `Ctrl+d` |

## Windows

| Action | Key |
|--------|-----|
| New window | `prefix` + `c` |
| Rename window | `prefix` + `,` |
| Switch by number | `prefix` + `0-9` |
| Next window | `prefix` + `n` |
| Previous window | `prefix` + `p` |
| Move window to session | `prefix` + `.` |

## Sessions

| Action | Key |
|--------|-----|
| List sessions (interactive) | `prefix` + `s` |
| Rename session | `prefix` + `$` |
| Next session | `prefix` + `)` |
| Previous session | `prefix` + `(` |

## Misc

| Action | Key |
|--------|-----|
| Reload config | `prefix` + `r` |
| Copy mode | `prefix` + `Enter` |
| Paste | `prefix` + `p` |
